OpenClaw Automations

A private, single-user automation setup that connects Google Workspace services to a self-hosted n8n instance and an OpenClaw assistant.

What it does

OpenClaw Automations is a personal tool. It is operated by one person, for that person's own accounts. There is no public sign-up, no shared service and no other users.

  • Google Calendar — read and create events from automated workflows.
  • Google Drive — create and organise files and folders produced by workflows.
  • Google Sheets — read and append rows used as workflow input and output.
  • Gmail — read and send messages on behalf of the account owner.

How it runs

Workflows run on a private server controlled by the account owner. Access to the workflow interface is protected by HTTP authentication and two-factor authentication, and all traffic uses HTTPS. OAuth tokens are stored encrypted on that server and are never shared.

This application is not distributed, sold or offered to third parties. It exists only to automate the operator's own work.
